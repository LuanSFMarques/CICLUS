# CICLUS v1.0
*CICLUS* é Software para acompanhamento do ciclo de vida de equipamentos laboratoriais na empresa Suporte, garantindo fácil acesso às informações e total visibilidade do histórico e status de cada equipamento.

## Funcionalidades Principais

- Visualização completa da lista de equipamentos armazenados no banco de dados, com fácil acesso a informações essenciais como status, calibração, modelo, ID corporativo, entre outros.
- Criação e edição de equipamentos diretamente pelo software, garantindo atualização ágil e segura.
- Interface intuitiva com uso de cores que melhoram a experiência do usuário.
- Barra de pesquisa avançada por múltiplos fatores, permitindo localizar rapidamente equipamentos específicos utilizando nome e demais atributos.
- Registro detalhado do histórico de cada equipamento, com possibilidade de criação e edição de eventos, oferecendo visão completa dos acontecimentos de forma eficiente.
- Atualização automática de metadados dos equipamentos ao criar novos itens, reduzindo o número de ações necessárias para manter as informações atualizadas.

## Tecnologias Utilizadas
- **Python**: Linguagem principal do software
- **TKinter**: Criação da interface gráfica.
- **SQLite3**: Banco de dados local para armazenamento rápido e leve.

## Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/LuanSFMarques/CICLUS
```

2. Navegue até a pasta do projeto:
```bash
cd CICLUS
```

3. instale dependências:
```bash
pip install -r requirements.txt
```

4. execute o programa:
```bash
python main.py
```
ou
```bash
py main.py
```
